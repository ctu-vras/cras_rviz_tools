# cras\_rviz\_plugins

Various plugins used and developed by CRAS.

## ROS versions compatibility

| ROS | Support |
|-----|---------|
| Humble | Not supported |
| Jazzy | Until EOL |
| Kilted | Until EOL |
| Lyrical | Until EOL |
| Rolling | Best effort |

## Licensing

If not said otherwise, plugins in this repo are released under BSD-3-Clause license.

## Tools

> [!NOTE]
> Tools allow interacting with RViz.

- [rviz_zone_of_interest_tool](rviz_zone_of_interest_tool) (Apache-2.0 license): Provides an RViz tool that can define polygonal zones of interest.

## Displays

> [!NOTE]
> Displays allow visualizing topic data.
